# بوابة TV Pro على خادم خاص (VPS)

بوابات Deno وCloudflare تعمل من عناوين مراكز بيانات معروفة، وكثير من مزوّدي IPTV يحظرها (ظهر ذلك كـ "Blocked" أو `error code: 1003`).
خادم خاص بعنوان IP نظيف، يُختار في بلد يقبله المزوّد، هو الحل الأضمن. الكود نفسه (`tvpro-gateway-deno.ts`) بلا تعديل.

## التشغيل
1. استأجر VPS صغيرًا (1 vCPU / 1 GB يكفي) في بلد قريب من المزوّد، وثبّت Docker.
2. أضف سجل DNS من نوع A: `gw.tv-pro.app` يشير إلى IP الخادم (بدون وكيل Cloudflare، أي سحابة رمادية).
3. على الخادم:
   ```bash
   git clone https://github.com/abu00salman/tvpro && cd tvpro/gateway-vps
   GATEWAY_DOMAIN=gw.tv-pro.app docker compose up -d --build
   ```
   شهادة HTTPS تصدر تلقائيًا عبر Caddy.
4. اختبر: `curl -I https://gw.tv-pro.app/` يجب أن يردّ بدل أن ينقطع.
5. أضف `https://gw.tv-pro.app` أولًا في قائمة البوابات (الإعدادات ← البوابات، أو `TVPRO_GATEWAYS`).

## ملاحظات
- هذا ليس وكيلًا مفتوحًا: البوابة تمنع الشبكات الداخلية (SSRF) ولا تسجّل روابط البث.
- لا يوجد حل مضمون 100%: إن كان المزوّد يحظر عنوان الخادم نفسه فجرّب مزوّد استضافة أو بلدًا آخر.
- بديل منزلي: شغّل نفس الحاوية على جهاز في بيتك ووصّله عبر Cloudflare Tunnel، فيخرج الطلب بعنوان بيتك.
